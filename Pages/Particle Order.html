Particle Order

Particle order is as the name implies, the order in which each particle in the save is read every frame

When the player places a particle of anything (excluding walls), each new particle receives the next particle ID in the order it was placed.

However, every time you save it, such as online saving or stamping, the particle order changes to a very predictable order.

Once saved, the game scans particles like reading a book: starting from the top row, moving left to right, then continuing onto the next row until every particle has been processed, (in the case of stacked particles it reads from the bottom of the stack to the top), every single frame 60 times a second.

By manipulating this predictable particle order we can make something known within the community as subframe tech.
